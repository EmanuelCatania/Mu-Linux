# Tema WebzenOldSchoolV2

Diseño del launcher "WebzenOldSchoolV2" de kayito (NicoMuratona), tomado de
https://github.com/nicomuratona/kayito-MuLauncher (carpeta `3.WebzenOldSchoolV2`).
Su autor dio permiso para usarlo en este proyecto (2026-11-20, por Discord); su
repo no tiene licencia, así que el crédito va acá y en la ventana del launcher.

Las imágenes son las del original, sin cambios.  Es la versión oscura del V1:
ventana de 450x436, botones de 90x28 con texto claro, barra de progreso gris
oscura.  Medidas y colores de su `Forms/Main.Designer.cs`.  La pantalla de
opciones usa su `OptionsBackground.png`, oscurecida para que se lean las
pestañas.  Se compila con `-DMU_LAUNCHER_THEME=WebzenOldSchoolV2`.

`MainImage.png` es arte de MU Online (Webzen).
